# Sameena P — AI & Data Science Portfolio

> An immersive, interactive 3D portfolio and scientific workbench showcasing machine learning models, full-stack applications, and real-time AI capabilities.

---

## 🌟 Overview

Welcome to the personal developer portfolio and scientific showcase of **Sameena P**, an **AI & Data Science Engineer, Full-Stack Developer, and UI/UX Designer** based in Chennai, India.

This project delivers an interactive, high-performance experience with real-time 3D visuals, live AI chat powered by Gemini, interactive project diagnostics, and deep learning exploration tools.

---

## 🚀 Key Features

- **Interactive 3D Visual Experience**: Dynamic scene rendering with Three.js and fluid animations powered by Motion.
- **Integrated Gemini AI Assistant**: Multi-turn contextual assistant capable of discussing projects, technical architecture, and research background.
- **Scientific AI Workbench**: Interactive exploratory tool demonstrating data preprocessing, feature normalization, and comparative evaluation across machine learning models.
- **Featured Projects Showcase**:
  - **Diabetes Prediction System** (Python, Machine Learning, Streamlit): Comparative evaluation of Logistic Regression, Decision Tree, Random Forest, and KNN.
  - **Brain Tumor Detection Using MRI** (TensorFlow, CNN, Streamlit): Deep learning convolutional neural network for cranial MRI classification.
  - **SEO Brilliance** (React, Node.js, PostgreSQL): SaaS platform for automated SEO auditing and recommendations.
  - **InstaGuard AI** (React, Node.js, MongoDB): AI safety platform concept featuring harassment detection and incident analytics.
  - **Annapathiram Catering Platform** (React, FastAPI, MongoDB): Hospitality web application with booking, media management, and analytics.
- **Secure Contact & Inquiry System**: Real-time communication and inquiry tracking powered by Firebase Firestore.

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Sameena-lang/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables:
   ```bash
   cp .env.example .env
   ```
   Add your Gemini API Key in `.env`:
   ```env
   GEMINI_API_KEY="your_actual_gemini_api_key"
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
